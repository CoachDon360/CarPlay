UPLOAD
Upload every file in this ZIP directly to the ROOT of the GitHub Pages repository:
- index.html
- home.css
- home.js
- home-wallpaper.png
- README.txt

CHANGES
- Removed the glass header.
- Temperature and live time now float in the upper-right.
- Reduced status typography.
- Removed empty glass placeholders.
- Added a balanced 4 x 3 app-icon framework.
- Moved the grid slightly lower for more breathing room.
- Added automatic cache-busting version 003.

NAMING STANDARD
- Keep files in the repository root.
- Every feature file begins with its feature name.
- Feature assets follow feature-description.ext.
  Examples: radio-klove.png, radio-yacht-rock.png, disney-epcot.png.
- index.html remains the one required GitHub Pages exception.

This foundation intentionally uses neutral starter app artwork. Final icons and links can be replaced feature by feature.
